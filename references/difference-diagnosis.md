# 原站与本地不一致的诊断

相同代码不保证相同画面：数据、组件状态、容器尺寸与运行环境都是输入。先对齐输入，再判断是否是复刻缺陷；不能先通过 CSS、硬编码坐标或修改数据来贴合截图。

## 排查顺序

1. **确定比较基准。** 标明用户截图、实时原站和本地快照分别对应的 URL、日期与版本。用户要求复刻历史截图时，保留它作为目标；当前原站只作为辅助证据。历史数据取不到时明确缺口，不能悄悄换成最新版并称一致。
2. **核对数据完整性。** 检查资源哈希、解密/解析结果、记录 ID、关键值、模型集合及转换后的图表 props。抓取时间相同不代表数据相同；数据数量相同也不代表内容相同。
3. **对齐状态。** 检查 pathname/query、标签、筛选、选择项、前沿自动添加、固定高亮、hover、图例、说明展开及设置。记录默认值与实际值，不只看 URL。
4. **对齐呈现环境。** 统一视口、deviceScaleFactor、缩放、浏览器、主题、语言、字体加载和滚动位置；等待相关数据、hydration 与动画稳定，不只等待任意固定时间。
5. **检查资源与适配。** 阻断外网，核对缺失文件、错误 MIME、JS 异常、fallback 字体、后台请求和本地 CSS/导航注入。必要时在临时副本中逐项禁用适配定位，不破坏用户现有页面。
6. **归类并处理。** 修复本地缺陷；解释已确认的输入差异或范围限制；无法定位的保留为待查，不归为正常差异。

## 差异原因表

| 原因 | 可见表现 | 应收集的证据 | 处理原则 |
| --- | --- | --- | --- |
| 数据版本变化 | 分数、速度、排序、坐标范围变了 | 同一模型 ID 的源/本地字段值、数据哈希、捕获时间 | 按用户目标保留历史快照或更新整套兼容快照，不混用旧 HTML/密钥和新数据 |
| 完整数据加载失败 | 有图但模型少、搜索不到、筛选结果异常 | 请求状态、原始字节、解密/JSON 结果、SSR 子集与完整数据对照 | 属于缺陷，修复下载/映射；不能因为 SVG 出现就通过 |
| 模型集合或前沿候选不同 | 点数量、Pareto 线、轴范围不同 | 选中 ID、自动添加 ID、候选池与过滤规则 | 先对齐集合；点数变化不一定是绘图代码改变 |
| 详情页与总榜状态不同 | 一个模型突出，其他模型淡化 | 路由、初始 props、focusModelIds、点 opacity | 保留各页面真实初始状态，不能只改总榜标题冒充详情页 |
| query 或初始化丢失 | 默认标签错误、刷新后状态重置 | 完整 URL、aria-selected、hydration 时序、实际事件 | 修复状态恢复与事件处理；不能只往地址栏写正确参数 |
| 交互瞬时状态不同 | 提示框、图例淡化、折叠说明不一致 | 鼠标位置、hover 目标、选中项、aria-expanded | 用相同操作序列复现，截取稳定状态；与固定模型高亮分开判断 |
| 视口、字体或环境不同 | 换行、标签间距、图例布局、颜色不同 | viewport/DPR/缩放、computed style、字体加载结果、主题/语言 | 对齐环境；微小抗锯齿差异与明显布局错误分别记录 |
| 懒加载或渲染尚未完成 | 空白图、旧标签、导出空白 | 资源完成状态、目标内容、动画/字体状态 | 等明确完成条件；有界重试，不用无限循环强制默认状态 |
| 本地容器/导航适配 | 边距、宽度、侧栏、遮挡与原站不同 | 原站/本地容器尺寸、CSS 差异、用户授权范围 | 独立图表移除侧栏属于预期适配；额外遮挡或无意裁切仍是缺陷 |
| 资源缺失或缓存掩盖 | 字体回退、图标缺失、断网后失效 | 新 context 下的请求记录、MIME、hash、JS 错误 | 补齐资源；不能把未知外部请求都说成遥测 |
| 后台未复制 | 登录、实时数据、付费导出无法完成 | 原站操作结果、依赖接口及权限状态 | 明确功能边界，保留权限提示，不伪造成功 |
| 原站已有布局问题 | 手机标签拥挤、轴文字裁切 | 同尺寸、同状态的原站/本地对照截图 | 只有原站确有相同表现才能这样归类；默认保留，优化需符合用户意图 |

## 实战故障与回归检查

| 现象 | 判断证据 | 修复 | 必须重验 |
| --- | --- | --- | --- |
| hydration 后正文消失、Connection closed | Flight 文本记录的长度前缀与被替换的字节不符 | 不全局替换 HTML/Flight，仅处理资源属性和运行时映射 | 长度前缀样本、完整页标题及 hydration |
| 相同 URL 图标差几个像素或哈希不符 | 浏览器 Accept 返回 WebP，其他抓取通道返回另一编码；URL 文件名覆盖 | 内容哈希文件、记录响应变体、确定浏览器版本优先级 | 磁盘哈希与同视口图标像素 |
| Apply 后空白 | 所有 RSC 请求被统一取消 | 区分预取和真实导航，捕获目标状态并整页跳转 | radio → Apply → 准确 URL → 内容和图表 |
| 新状态有 HTML，但按钮不工作 | 引用另一部署的 CSS/runtime/路由模块且请求 404 | 对新增状态再次补齐依赖 | 页面错误、标签状态与异步数据 |
| API 返回 200 但 JSON 解析失败 | 响应实际是 SPA fallback HTML | 缺失 API 显式错误，精确匹配请求 | MIME、schema 和业务字段 |
| 有曲线，但换模型不对 | 老 middleware 返回固定 POST 快照，返回 ID 不属于请求 | 对模型/端点选择做结构化回放，修正 handler 优先级 | 返回 ID 集合、切换选择、原页回归 |
| 点击历史标签的测试通过但没数据 | 快速循环未等异步请求，或只断言 aria-selected | 等请求完成及实际结果，保留源站空数据/权限 | 请求参数、点数/已知字段、权限提示 |
| 源/本地截图差别极大 | 截图前误导航到其他页，或继承上一分支 query | 每次核对 URL/状态、恢复基线 | 截图对应 route、视口及选项 |
| 图表在并发模式消失 | 同动作操作原站也缺标签或提示不支持 | 保留真实限制，不补虚构数据 | 原站/本地限制文字或标签集合 |
| 媒体能加载却不能拖进度 | Range 请求未得到正确 206/Content-Range | 实现普通、suffix、不可满足范围和 HEAD | 真实播放、seek、206/416 字节范围 |
| 代码已改但浏览器仍走旧逻辑 | 服务进程尚未加载 middleware 导入变更 | 重启所属服务而非盲改更多前端 | dev 和生产 preview 的实际响应 |
| 本地源码/素材准备开源时混入抓取产物 | 发布目录包含 snapshot、数据、绝对路径或凭据 | 仅发布工具与可再分发文档，分开素材权利 | 发布包文件清单、忽略规则及内容扫描 |

## 验收记录格式

对每个重要差异留下简短记录，不要求为每一个像素单独建文档：

```text
现象：
目标基准：截图/URL/版本或未知项
源与本地证据：截图、状态、字段值或请求记录
已排除的原因：
归类：快照输入差异 / 预期适配 / 原站已有问题 / 后台范围限制 / 本地缺陷 / 待查
处理与复验结果：
剩余限制：
```

在报告中分开说明视觉一致性、数据完整性、交互可用性和离线独立性。交互通过不能推出像素一致；没有页面横向溢出不能推出局部文字可读；图片导出成功不能推出付费数据导出可用；复用了原站 JS 不能推出全部后台功能已复刻。

当历史截图缺少 URL/时间/模型选择信息时，先利用已有 HTML、数据和当前原站推进对照，再询问决定性缺失信息。不要凭推测把某个差异归因到快照版本。
